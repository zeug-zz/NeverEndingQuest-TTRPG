## Context

The archived `toolkit-accurate-ingest-final-reconciliation-boundary` change established provider-free classification and status plumbing. Editorial blockers now produce `final_reconciliation_required` plus a workspace-local `final_reconciliation_brief.json`. Report agreement can already accept a valid final reconciliation report and preserve source-fidelity honesty through `source_fidelity_effective_status: reconciled_degraded`.

This change implements the missing provider-backed final editor that turns a required reconciliation brief into validated module changes and an accepted report.

## Architecture Boundary

Contract Layer (MUST):

- The front and middle pipeline SHALL remain unchanged.
- The final editor SHALL consume artifacts produced by the existing boundary and SHALL NOT rewrite source truth artifacts.
- The final editor SHALL operate only at the final editorial/publication boundary after ModuleBuilder output exists.
- Python validation SHALL remain authoritative for JSON/schema/readiness/publishability/report agreement.

Guidance Layer (SHOULD):

- Add the final editor as `utils/toolkit_llm_final_reconciliation.py` with small pure helpers for prompt assembly, patch parsing, patch validation, patch application, and report construction.
- Add prompt text under `prompts/toolkit/final_reconciliation_builder_prompt.txt`.
- Integrate from `web/extensions/toolkit_homebrew_packet_builder.py` at the existing `final_reconciliation_required` branch.

## Key Decisions

### Decision 1: Fix reconciliation artifact path safety first

Contract Layer (MUST): artifact persistence and atomic-lock paths SHALL be derived from file paths, not serialized payloads. Passing swapped path/payload arguments or payload-as-path SHALL fail safely before creating oversized lock names.

Guidance Layer (SHOULD): add targeted regression coverage near the reconciliation helpers or file-operation helper that reproduces the Errno 63 class without relying on OS-specific path limits.

### Decision 2: Final editor emits a patch plan, not freeform prose

Contract Layer (MUST): the LLM final editor output SHALL be strict JSON matching a stable patch contract. Freeform prose, markdown fences without parseable JSON, invalid JSON, or missing required keys SHALL fail closed.

Guidance Layer (SHOULD): allow helper extraction for stripping markdown fences before JSON parse if existing codebase patterns already support that style.

### Decision 3: Patch application is Python-gated

Contract Layer (MUST): Python SHALL validate every file target, decision type, patch shape, and source-fidelity claim before writing any module file.

Guidance Layer (SHOULD): prefer validating the entire patch plan before applying the first write to avoid partial mutation.

### Decision 4: Source fidelity remains honest

Contract Layer (MUST): accepted reconciliation SHALL NOT convert blocked source fidelity into clean `pass`. Reports SHALL preserve original source-fidelity status and expose `source_fidelity_effective_status: reconciled_degraded`.

Guidance Layer (SHOULD): GUI wording from the archived boundary should be reused unless additional final-editor status copy is necessary.

### Decision 5: Retry budget is bounded

Contract Layer (MUST): if post-reconciliation validation fails with repairable issues, the system SHALL allow at most one retry to the final editor with validation errors. Infinite retries SHALL NOT be possible.

Guidance Layer (SHOULD): persist first-attempt diagnostics in the workspace so failures remain inspectable.

## Patch Contract

The final editor patch SHOULD use this shape unless implementation finds an existing patch contract to reuse:

```json
{
  "version": "accurate_ingest_final_reconciliation_patch.v1",
  "status": "ready",
  "source_fidelity_claim": "reconciled_degraded",
  "publication_intent": "playable_module",
  "decisions": [
    {
      "blocker_message": "Required location 'Trigger' not found in module",
      "decision": "delete_bogus_atom",
      "from": "required_location",
      "to": "mechanic_heading",
      "reason": "Trigger is a trap mechanics heading, not a playable location"
    }
  ],
  "file_patches": []
}
```

Allowed decision types MUST be bounded: `delete_bogus_atom`, `reclassify_atom`, `merge_into_existing`, `preserve_as_dm_guidance`, `create_missing_real_element`, `refuse`.

Allowed target surfaces MUST be limited to canonical module artifacts listed in the reconciliation brief, such as `module_context.json`, `module_context_BU.json`, `module_plot_BU.json`, `areas/*_BU.json`, and `map_*.json`. Runtime-only files MUST be rejected unless generated by existing canonical-to-runtime tooling after validation.

## Integration Points

- `utils/toolkit_final_reconciliation.py`: load/persist existing brief/report artifacts and accepted report checks.
- `utils/toolkit_llm_final_reconciliation.py`: new final editor runner and patch safety logic.
- `web/extensions/toolkit_homebrew_packet_builder.py`: invoke final editor when `final_reconciliation_required` is reached and retry/continue when accepted.
- `web/extensions/toolkit_module_finisher.py`: consume accepted report; existing boundary support should remain compatible.
- `utils/file_operations.py` or call sites: fix path/lock safety if payload-as-path can occur.

## Migration And Rollback

Migration is additive. Existing workspaces that stop at `final_reconciliation_required` can be reprocessed by the new final editor. Rollback disables final-editor invocation and leaves the previous boundary behavior intact.
