## ADDED Requirements

### Requirement: Source Monster Refs Finalize To Artifacts Or Diagnostics

Numillian source monster references SHALL become module-local schema-valid monster artifacts through reuse-first resolution or remain explicit unresolved diagnostics.

#### Scenario: Source monster ref is safely reusable
- **GIVEN** a source monster ref maps to an existing reusable template or schema-valid module-local artifact
- **WHEN** monster finalization runs
- **THEN** a schema-valid `monsters/*.json` artifact SHALL exist for that ref
- **AND** materialization/report output SHALL count it as reused or generated by a safe reuse path.

#### Scenario: Source monster ref is ambiguous or unavailable
- **GIVEN** a source monster ref has no safe reusable monster source
- **WHEN** monster finalization runs
- **THEN** the ref SHALL remain unresolved in diagnostics
- **AND** no invented replacement monster SHALL be written.

#### Scenario: NPC-like source name lacks monster evidence
- **GIVEN** a source name is an NPC or character without monster/combatant evidence
- **WHEN** monster finalization runs
- **THEN** the name SHALL NOT be materialized as a monster artifact.

## SHOULD Guidance

Reuse existing accurate-ingest monster materialization helpers and module monster authority/hydration utilities before adding new mechanisms.
