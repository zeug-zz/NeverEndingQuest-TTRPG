## Why

The Numillian release-proof pass exposed a critical accurate-ingest failure: source reports can identify missing narrative essentials, but the pipeline does not yet force an LLM Builder repair pass to reconstruct those essentials from the human-written source. Kobe and the first skull riddle are not optional details; they are the final trial objective and the first gate into Shuluth's mind.

Python should not manually author these repairs. Python should provide deterministic evidence, source excerpts, source-lock constraints, and validation gates, then route the problem back to the LLM Builder/backstage assistant for source-faithful narrative synthesis.

## What Changes

- Add deterministic detection for critical prose-named actors that are absent from final module NPC/scene surfaces.
- Add deterministic detection for explicit trial/riddle/puzzle structures that are absent from final module plot or puzzle surfaces.
- Add a backstage repair brief artifact that packages missing critical content, source excerpts, target output surfaces, and source-lock constraints for the LLM Builder.
- Add an LLM Builder repair pass that consumes the repair brief and updates module JSON through source-faithful narrative synthesis.
- Add release verification that requires Numillian to preserve Kobe and `skull_riddle` from live module JSON, not stale report artifacts.

## Capabilities

### New Capabilities

- `accurate-ingest-critical-narrative-omission-detection`: Detect critical prose actors and explicit puzzle/trial structures missing from final module JSON.
- `accurate-ingest-builder-repair-briefing`: Produce Builder-facing repair briefs from deterministic omission evidence and source excerpts.
- `accurate-ingest-llm-builder-repair-pass`: Route repair briefs to the LLM Builder and persist source-faithful repaired module artifacts.
- `accurate-ingest-narrative-plot-topology-preservation`: Preserve adventure-arc plot structure separately from map-key/location structure.
- `accurate-ingest-critical-repair-release-verification`: Verify repaired modules through live benchmark, validation, report, and publishability gates.

### Modified Capabilities

- `accurate-ingest-builder-audit-next-step-routing`: Backstage audit next-step routing must route critical narrative omissions to Builder repair rather than only reporting diagnostics.
- `accurate-ingest-builder-audit-brief-output`: Audit brief output must include critical narrative repair evidence when source-fidelity blockers identify missing critical actors or puzzles.
- `accurate-ingest-generator-source-contract`: Source contracts must distinguish critical prose actors and puzzle components from table-only NPC/location extraction.

## Impact

- Affected code: accurate-ingest normalization/enrichment utilities, backstage audit/briefing scripts, ModuleBuilder handoff or repair entrypoint, source-fidelity report refresh path, and Numillian-focused regression tests.
- Affected artifacts: `builder_brief.json`/repair brief outputs, module JSON artifacts generated by the Builder repair pass, and refreshed source-fidelity/toolkit/publishability reports.
- Provider behavior: The repair pass may require the configured LLM Builder provider. If the provider is unavailable, the repair job SHALL fail closed with actionable diagnostics; Python SHALL NOT silently invent or patch narrative content.
- Compatibility: Legacy module builds and non-source accurate-ingest paths SHALL remain unchanged unless a critical repair brief is explicitly present.
