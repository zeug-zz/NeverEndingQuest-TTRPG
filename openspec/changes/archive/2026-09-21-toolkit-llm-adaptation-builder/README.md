# toolkit-llm-adaptation-builder

Review-only OpenSpec scaffold for the LLM-led NEQ-TTRPG adaptation and publication lifecycle.

## Scope

- Adapt readable source material into a versioned dossier.
- Use ModuleBuilder as the creative construction engine.
- Use an LLM semantic auditor for one bounded final revision.
- Keep Python authoritative for validation, Markdown, reports, registry, and campaign visibility.
- Preserve accurate-ingest as an explicit legacy mode.
